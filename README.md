# センチメンタル・ハナエ

選択肢を選んで進める恋愛ADV。文化祭実行委員として出会った味村ハナエへの告白に成功すればクリア。

- 全20イベント + 自由行動パート(5択から3つ選択) + 隠しライバル「西野」による特殊分岐
- 好感度は非公開、ハートの演出(数・大きさ・動き)だけで反応を示す
- localStorageによるセーブ・中断・再開に対応
- モンテカルロ検証済みの難易度: 約58/100(初回成功率41.6%)

## 遊び方

`index.html` をブラウザで開くだけで動作します(ビルド不要、素のHTML/CSS/JS)。

## 構成

- `index.html` — 画面構造
- `style.css` — スタイル・ハート演出のアニメーション
- `game-data.js` — 全イベントのテキスト・選択肢・点数データ
- `game.js` — ゲーム進行エンジン
