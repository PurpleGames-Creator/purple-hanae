# センチメンタル・ハナエ

選択肢を選んで進める恋愛ADV。文化祭実行委員として出会った味村ハナエへの告白に成功すればクリア。

**遊ぶ: https://purplegames-creator.github.io/purple-hanae/**

- 全24イベント(固定19 + 自由行動プール5から3つ選択)＋隠しライバル「西野」による特殊分岐
- 好感度は非公開。ハートの演出(数・大きさ・動き)と、ハナエの反応だけが手がかり
- 背景7種・立ち絵2種(夏服/冬服)。パーフェクト達成時だけ季節が進んだ専用エピローグに入る
- エンディング6種。localStorage によるセーブ・中断・再開に対応

## 遊び方

`index.html` をブラウザで開くだけで動作します(ビルド不要、素のHTML/CSS/JS)。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面構造。ここが公開ファイル |
| `style.css` | スタイル・背景レイヤー・立ち絵・ハート演出 |
| `game-data.js` | 全イベントのテキスト・選択肢・点数・演出データ |
| `game.js` | ゲーム進行エンジン |
| `assets/` | 背景7点・立ち絵2点・OGP画像 |

## 難易度設計

バランスはモンテカルロで検証している(`SUCCESS_THRESHOLD` / `FRIEND_THRESHOLD` はその結果)。

| プレイヤーモデル | 成功率 |
|---|---|
| 一様ランダム(4択を等確率で選ぶ) | 約16% |
| 失礼・消極的な選択肢を避ける初回プレイヤー | 約96%(うちパーフェクト 約4%) |

**イベントの追加や点数の変更をしたら、必ず `SAVE_VERSION` を上げて再計測すること。**
上げ忘れると、古いセーブが新しい進行キューと噛み合わずに壊れる。

## 立ち絵の表情差分を追加する

立ち絵は**背景透過の全身像**で、画面下端に立たせている。現在は笑顔1種のみ。
以下のファイル名で `assets/` に置くと、エンジンが自動で使い分ける
(ファイルが無ければ `hanae_summer.webp` にフォールバックするので、1枚ずつ足してよい)。

| ファイル名 | 使われる場面 |
|---|---|
| `hanae_summer_joy.webp` | 好感度 +4 以上(ハート3つ) |
| `hanae_summer_smile.webp` | +1〜+3 |
| `hanae_summer_normal.webp` | ±0 |
| `hanae_summer_trouble.webp` | -1〜-2 |
| `hanae_summer_sad.webp` | 減点、かつ無神経ではない選択(落胆) |
| `hanae_summer_angry.webp` | 減点、かつ `tag:"pushy"` の選択(怒り) |

**冬服の差分は不要**(パーフェクトエピローグの1シーンにしか出ないため)。

元画像は `_source/` に置く。透過とwebp変換の手順は `_source/README.md` を参照。
