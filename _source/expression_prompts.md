# 表情差分の作り方とプロンプト集

2026-08-23 に夏服9種＋冬服1種を作った時の手順と、実際に使ったプロンプト。
**ストーリーを足して新しい表情が必要になったら、ここを見れば同じ品質で作れる。**

## 全体の流れ

1. ChatGPT のチャットに **参照画像を添付**して、下のプロンプトを投げる
   - 夏服 → `_source/ref_hanae_summer.png`
   - 冬服 → `_source/ref_hanae_winter.png`
2. 出力を `_source/hanae_<outfit>_<expr>_<日付>.png` として保存
3. 背景透過 → 位置合わせ → webp 変換(下記コマンド)
4. `game-data.js` の該当する選択肢の `expr` を新しい表情名にする

```bash
SC=/tmp   # 作業用の一時ディレクトリ

# 背景透過
uvx --from "rembg[cli,cpu]" rembg i -m isnet-anime _source/入力.png $SC/cut.png

# 位置合わせ(冬服は第3引数に assets/hanae_winter.webp を渡す)
uv run --with pillow --with numpy python _source/align_sprite.py $SC/cut.png $SC/aligned.png

# webp 化
ffmpeg -y -i $SC/aligned.png -c:v libwebp -pix_fmt yuva420p -quality 88 assets/hanae_summer_<expr>.webp
```

## なぜ位置合わせが必要か

ChatGPT は「編集」ではなく**顔ごと描き直す**ので、毎回わずかに違う構図・大きさになる。
実績値を見ると倍率は 0.62〜0.69 とばらついており、そのまま並べるとクロスフェードで顔が飛ぶ。

`align_sprite.py` は上半身シルエットの一致度(IoU)が最大になる倍率を探して合わせ込む。
**IoU が 0.90 未満なら警告が出る** — その場合はポーズか構図が元画像と違うので作り直した方が早い。

## プロンプトの共通部分

すべてのプロンプトはこの形。`【変えるのは表情だけです】` の中身だけを差し替える。

```
添付した画像の女の子の、表情だけを変えた画像を作ってください。

【絶対に変えないでほしいもの】
・髪型(高い位置のポニーテール、重めの前髪)と髪の色
・服装(白い半袖ブラウス、紺と赤のストライプのネクタイ、胸の校章ワッペン、グレーのチェックのプリーツスカート)
・ポーズ(正面を向いて立ち、両手は後ろ)
・構図(膝上まで入る縦長。顔の大きさと位置も同じ)
・背景(白一色、影なし)
・絵のタッチ、線の太さ、塗り方

【変えるのは表情だけです】
（ここに表情の指示）

同じキャラクターだと一目でわかるように、顔立ちは元画像から変えないでください。
```

冬服の場合は服装の行を次に差し替える:

```
・服装(紺のブレザー、ベージュのニットベスト、白いシャツ、紺と赤のストライプの蝶ネクタイ、校章ワッペン、グレーのチェックのプリーツスカート)
```

**蝶ネクタイ(リボン)であることを間違えない。** 設定資料の初稿は「ネクタイ」となっていたが、画像に合わせて蝶ネクタイで確定している。

## 表情ごとの指示

### normal(真顔)

```
何の感情も出ていない、落ち着いた真顔。
目はいつもどおりの大きさで、しっかり開いている。
まっすぐこちらを見ている。
口は閉じていて、まっすぐ。口角は上がっても下がってもいない。
眉は水平で、寄せても吊り上げてもいない。

笑っていません。かといって、悲しくも、怒ってもいません。
まぶたを伏せないでください(眠そうにしない)。
視線を下や横に逸らさないでください。
頬は赤くしないでください。

話を聞いている時の、ごく普通の顔です。
```

### soft(静かに心を許した顔)

```
穏やかで、静かな顔。
まぶたが少しだけ下がっていて、目が半分ほど伏せられている。
口は閉じていて、口元にごくかすかな微笑み。
視線はやや下向き。
肩の力が抜けて、警戒を解いた表情です。

はしゃいでいません。歯を見せて笑ってもいません。
頬は赤くしないでください(照れではありません)。
悲しくもありません。落ち着いて、安心している顔です。
```

### trouble(困り顔・苦笑い)

```
口を閉じた、困ったような苦笑い。
眉が少し下がっていて、視線をわずかに横へ逸らしている。
「まいったな」「参ったなあ」という顔。
かすかに笑ってはいるが、元画像のように口を開けて明るく笑っている顔ではありません。
悲しい顔でも、怒った顔でもありません。あくまで「困っている」表情です。
```

### lonely(寂しげ)

```
笑っていない、静かに寂しそうな顔。
視線がわずかに下を向いていて、目に少し力がない。
口は閉じていて、口角はわずかに下がっている。
何か言いたそうだけれど言わずに飲み込んだ、という表情。

泣いてはいません。涙も、目の潤みもありません。
怒ってもいません。困った顔でもありません。
「寂しい」とだけ書いてある、静かな顔にしてください。
```

### angry(ムッとした顔)

```
ムッとした、不機嫌な顔。
眉が少し吊り上がっていて、目にはっきりと力が入っている。
口は真一文字に結んでいる。
こちらをまっすぐ見て、「今なんて言うた?」と言いたげな顔。

怒鳴ってはいません。叫んでもいません。声を荒げる直前の、静かに機嫌が悪い状態です。
泣いてもいませんし、悲しんでもいません。
口は開けないでください。
```

### shy(照れ)

```
照れている顔。
頬がはっきりと赤くなっている。
視線をこちらから外して、少し横へ逸らしている。
口は閉じているか、ほんのわずかに開いている程度で、口元にかすかな笑み。
恥ずかしいけれど、嫌ではない。そういう表情です。

困ってはいません。怒ってもいません。悲しくもありません。
両手は後ろのままで、手で顔を隠したりはしないでください。
```

### surprise(驚き)

```
驚いている顔。
目を大きく見開いている。
眉が上に持ち上がっている。
口は小さく開いていて、「え」と言ったところ。
まっすぐこちらを見ている。

怖がってはいません。悲鳴を上げてもいません。
「思ってもみないことを言われて、一瞬固まった」という驚きです。
口を大きく開けすぎないでください。
頬は赤くしないでください。
```

### joy(満面の笑み)

```
心から嬉しそうな、満面の笑み。
目を細めて笑っている(元画像より、もっと細く)。
口を開けて、歯を見せて笑っている。
眉が上がって、顔全体で笑っている。
頬にうっすら赤み。

元画像もすでに笑顔ですが、それよりもさらに一段階うれしそうな顔にしてください。
元画像との違いがはっきり分かるようにしてください。
目を完全に閉じてしまわないでください(細めるだけ)。
口を開けすぎて叫んでいるようにはしないでください。
```

### cry(泣きそう)

```
泣きそうになるのを、こらえている顔。
目に涙がうっすら溜まって、瞳が潤んで光っている。
眉がわずかに下がっている。
口は閉じていて、口元がかすかに震えている。
こちらをまっすぐ見ている。

涙は流れていません。頬に涙のあとはありません。
声を上げて泣いてもいません。顔をゆがめてもいません。
悲しいのではなく、思いがけず嬉しくて胸がいっぱいになった表情です。
口を大きく開けないでください。手で顔を覆わないでください。
```

## 崩れた時の言い直し

ChatGPT は編集ではなく描き直しをするので、しばしば崩れる。そのまま続けて返す。

- `髪型と服装が変わってしまっています。元の画像と完全に同じにして、表情だけ変えてください。`
- `顔が別人になっています。添付画像と同じ顔立ちのまま、表情だけ変えてください。`
- `笑っています。まったく笑っていない顔にしてください。`
- `元画像との差が足りません。もっとはっきり変えてください。`

## 四十一歳のハナエと、似顔絵(2026-09-04 追加。素材待ち)

最下位の結末「四十一歳の似顔絵」で使う2枚。**assets/ に置いて登録するまで、ゲーム側は文だけで成立する**(立ち絵も CG も出ない)。

| ファイル | 中身 | 登録先 |
|---|---|---|
| `assets/hanae_adult_angry.webp` と `assets/hanae_adult.webp` | 四十一歳のハナエ。喫茶店のカウンターの奥から、本気で怒っている顔。`hanae_adult.webp` は同じ絵でよい(ベース扱い) | `game.js` の `SPRITE_EXPRESSIONS` に `adult: ["angry"]` を足す |
| `assets/cg_nigaoe.webp` | 似顔絵そのもの。進行表の裏紙に描いた稚拙な線画 | 登録不要(`endings.nigaoe.sceneChanges` が `cg: "cg_nigaoe"` で参照済み) |

### 四十一歳のハナエのプロンプト(夏服の参照画像を添付)

```
添付した画像の女の子が、24年後(41歳)になった姿を描いてください。同じ人物だと一目でわかるようにしてください。

【引き継ぐもの】
・顔立ち(黒目がちの大きな目、重めの前髪)。髪は黒のまま、肩までのボブか低い位置でまとめた髪
・健康的な体型(学生時代はテニス部の主将)
・ポーズ(正面を向いて立ち、両手は後ろ)と構図(膝上まで入る縦長。顔の大きさと位置も同じ)
・背景(白一色、影なし)、絵のタッチ、線の太さ、塗り方

【変えるもの】
・服装: 喫茶店を営む41歳の女性。白いシャツに黒のエプロン、袖をまくっている。制服やネクタイは無し
・表情: 本気で怒っている。眉を寄せ、口を結び、目はまっすぐこちらを見ている。怒鳴ってはいない
・年齢相応の落ち着き。ただし老けさせすぎない(41歳)
```

### 似顔絵のプロンプト(参照画像なし)

```
高校生の男子が、進行表の裏紙にボールペンで描いた「怒っている女子の似顔絵」を作ってください。

・A5くらいの白い紙(薄く罫線が透けている)。四つに折った跡と、黄ばみ。24年前の紙
・絵は稚拙で、線は勢い任せ。ポニーテールの女子が腕組みをして目を吊り上げている
・口から吹き出しが出ていて、中に「はよ動け」と手書きの字
・紙全体を正面から撮った構図。背景は無し(紙だけ)
・上手く描かないこと。中学生の落書きくらいの画力で
```

変換: 立ち絵は夏服と同じ手順(rembg → `align_sprite.py` の第3引数は不要。**大人の立ち絵は夏服と身長が違ってよい**ので位置合わせはしない)。似顔絵は透過不要、`ffmpeg -i in.png -c:v libwebp -quality 88 assets/cg_nigaoe.webp`。
